# Avatar options

`p1-head.png` and `p2-headshoulder.png` are recrops of the existing profile
photo, recentred on the face. GitHub renders avatars as circles and shows them
at 32px in comment threads, so the original wide framing loses the face at
small sizes. Upload one at Settings → Profile → Profile picture.

The monogram files are fallbacks, kept in case a drawn mark is ever wanted
instead of the photo. They use the ShellPilot palette: #22c7d6 on #0d1119.

| File | What it is |
|---|---|
| `p1-head.png` | Tight crop — best legibility at small sizes |
| `p2-headshoulder.png` | Classic headshot framing |
| `c-inverted.png` | AW monogram, dark letters on a cyan disc |
| `d-ring.png` | AW monogram inside a cyan ring |
| `e-terminal-disc.png` | Terminal prompt mark on a cyan disc |
| `_current-github*.png` | The avatar as it is today, for comparison |
| `_preview.png`, `_photo-preview.png` | Contact sheets at 260 / 64 / 32px |
